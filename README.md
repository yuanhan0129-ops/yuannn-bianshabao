# 皮卡丘快跑！

使用 Phaser 3 製作的橫向跑酷遊戲。線條風格的皮卡丘會自動奔跑，穿越沙漠、海灘與台北都市三個場景，並以十萬伏特擊倒每個場景的敵人。

## 開始遊戲

直接用瀏覽器開啟 `index.html`，或造訪 GitHub Pages 網站。Phaser 3.90.0 由 jsDelivr CDN 載入，遊玩時需要網路連線。

## 操作方式

- 空白鍵或向上鍵：開始／跳躍
- Z 鍵或「十萬伏特」按鈕：擊倒進入攻擊範圍的敵人
- 向下鍵：蹲下
- 手機／平板：點擊左側跳躍、按住右側蹲下，並點擊「十萬伏特」按鈕
- 每超過 500 分會更換場景：沙漠（噴火龍）、海灘（傑尼龜）、台北都市（烈空坐）
- 每 500 分提高一次奔跑速度；分數超過 1500 後仍可繼續遊玩
- 超過 1500 分後倒下時，顯示「挑戰成功！恭喜成為寶可夢大師」
- 遊戲結束或通關後選擇「再玩一次」或按 R 重新開始

最高分會儲存在目前瀏覽器的本機儲存空間。
