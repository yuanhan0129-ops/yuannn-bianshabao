# 皮卡丘快跑！

使用 Phaser 3 製作的橫向無盡跑酷遊戲。線條風格的皮卡丘會自動奔跑，玩家要跳過仙人掌；遇到線條風格噴火龍時，使用十萬伏特擊倒牠才能通過。

## 開始遊戲

直接用瀏覽器開啟 `index.html`，或造訪 GitHub Pages 網站。Phaser 3.90.0 由 jsDelivr CDN 載入，遊玩時需要網路連線。

## 操作方式

- 空白鍵或向上鍵：開始／跳躍
- Z 鍵或「十萬伏特」按鈕：擊倒進入攻擊範圍的噴火龍
- 向下鍵：蹲下
- 手機／平板：點擊左側跳躍、按住右側蹲下，並點擊「十萬伏特」按鈕
- 遊戲結束後選擇「再玩一次」或按 R 重新開始

最高分會儲存在目前瀏覽器的本機儲存空間。
